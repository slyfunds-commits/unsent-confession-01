A micro-confession for the make.fun bounty [Unsent — The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba): a message to a grandfather, written and never sent.

`main.py` writes the 99-byte entry to `/output/entry.txt` with no trailing newline.

The confession is a re-introduction: the sender knew their grandfather had forgotten their name at Christmas, so they introduced themself like they'd never met — a grievance that dissolves into tenderness.
